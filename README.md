# Alex Mobile Mechanic LLC — premium website

Deploy the folder to a static host such as Vercel. Includes 14 dedicated service pages, estimate request page, actual user-supplied repair photographs, testimonials, responsive styling.

**Important:** The $999 figure is a conspicuously labeled demonstration placeholder, NOT a real estimate. Estimate requests open SMS or email apps; there is no backend submission, automatic price calculation, or payment processing. Owner should confirm the service list, review excerpts, contact email, business address, and coverage before publication. The images were provided by the client; verify usage permission.

Preview locally: `python -m http.server 8000` in this directory; visit http://localhost:8000.
